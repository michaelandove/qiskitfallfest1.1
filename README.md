---

## 📌 Overview

**Qiskit Fall Fest** is a global series of student-led quantum computing events supported by IBM Quantum. The 2026 Nairobi edition brings together undergraduate students, researchers, developers, and tech enthusiasts across Africa to learn quantum mechanics fundamentals, build applications using the open-source **Qiskit SDK**, and compete in real-world hackathon challenges.

* **🗓️ Dates:** October 18, 2026 – November 13, 2026
* **📍 Venue:** Kenyatta University Main Campus (Physical) & Virtual (Online)
* **🎟️ Registration:** [Register Here](https://forms.gle/cGXpDa88s2ShDuq16) *(100% Free)*
